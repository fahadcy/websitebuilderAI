# AI Website Builder - Speaker Notes

## 1. AI Website Builder
This project is a SaaS platform that turns a business idea into a complete website package. The long-term vision is bigger than basic prompt-to-page generation: it should become a guided, inspected, editable, and self-improving website production system.

## 2. The Problem
Most AI website builders can create something that looks impressive for a moment, but the result often feels repetitive, shallow, or unfinished. Real businesses need better copy, stronger SEO, contact flows, admin tools, deployment readiness, and quality checks before a client sees the site.

## 3. Product Concept
The product has two main layers. The first layer is the builder application, where the user submits a prompt, uploads a logo, reviews suggestions, checks domain ideas, and generates the site. The second layer is the generated website itself, including pages, SEO, forms, maps, admin CMS, and deployment files.

## 4. Generation Journey
The intended journey starts before the prompt. If the company is registered, the builder can ask about Companies House, search the company, and use official details such as business name and address. Then it improves the prompt, asks relevant questions, generates the site, checks the output, and lets the user edit and teach the system.

## 5. What It Can Do Now
The application can guide the user through prompt review, Companies House flow, domain suggestions, logo upload, AI-assisted generation, SEO planning, visual editing, and site packaging. Generated websites can include multiple pages, content, images or fallback images, CMS files, contact capture, maps fallback, and deployment documentation.

## 6. Generated Website Output
Each generated website should be treated as a business asset. The output is not just an index page. It includes core pages, editable content, SEO metadata, keyword planning, contact forms, newsletter capture, sitemap, robots, RSS, schema, admin CMS, database schema, and a ZIP package.

## 7. Honest Limits
The product does not automatically retrain GPT by itself. Domain availability is not yet registrar-grade. Companies House only helps for registered UK businesses and depends on API/configuration reliability. AI image generation depends on API access. The visual editor is useful, but it is not yet a full Webflow or Figma-level canvas.

## 8. Reality Check Agent
The Reality Check Agent is a quality layer. It should check missing files, broken links, weak content, placeholder sections, SEO coverage, security signals, CMS readiness, and packaging. This is one of the most important differentiators because it moves the product from "AI generated something" to "AI checked whether the thing is usable".

## 9. Teaching Layer
The teaching layer is the current practical way for the system to learn. The user gives feedback on what was good, what was wrong, and what should change. The system stores that feedback, turns it into rules, and applies relevant guidance to future generations.

## 10. Data Flywheel
Over time, the product can collect structured feedback by industry, prompt type, page structure, design direction, image choice, SEO keywords, and conversion outcomes. This data can build industry playbooks, retrieval memory, scoring models, evaluation tests, and eventually a clean training dataset.

## 11. Trust And Governance
Client data must be handled carefully. The system should only use feedback for learning with consent. It should not train on secrets, private documents, API keys, personal data, or sensitive business details by default. Admins should be able to inspect, disable, delete, and export learning rules.

## 12. Roadmap
The next product steps are: improve layout diversity and typography, strengthen logo/image placement, upgrade the visual editor, add conversion analytics, build stronger feedback labels, introduce vector memory, improve deployment integrations, and add full Lighthouse/security/accessibility checks.

## 13. Why It Can Win
The strongest positioning is not "AI builds a website". The strongest positioning is "AI gets better at building the right website for each business". The moat is the combination of guided brief, generation, quality inspection, editing, feedback memory, and industry-specific learning.
